# 电信天邑 TEWA-1100G 光猫超密获取工具（避坑版）

针对 **天邑 TEWA-1100G（博通版，TY968560CTNW）** 电信光猫的超级管理员密码一键获取工具。

## ⚠️ 重要：仅适用于博通版

天邑 TEWA-1100 系列有**博通版**和**海思版**两种芯片方案，SU 密码算法不同。

* ✅ 博通版：板卡 `TY968xxx`（如 TY968560CTNW）→ 本工具适用
* ❌ 海思版：板卡 `Hi5682` 等 → 本工具不适用，su 会提权失败

**判断方法**：登录 8080 后台后，F12 在首页源码搜 `BoardId`，看是 `TY968` 还是 `Hi5682`。

## 背景

电信下发时会把 `telecomadmin` 的默认密码 `nE7jA%5m` 改成随机密码，普通用户 `useradmin` 无法在 Web 后台看到它。本工具通过以下可逆链路找回超密：

1. 登录 8080 维护后台（useradmin）
2. 抓取设备管理页泄露的 `set3\_sessionKey`
3. 调用 `telandftpcfg.cmd` 临时开启 Telnet
4. Telnet 登录 → `su` 提权（SU 密码由 MAC 经固定算法生成）
5. `exit` 退回厂商 CLI → `telecomadmin get` 直接读取超密
6. 自动关闭 Telnet 恢复原状

**全程不改宽带 / WiFi / 拨号配置。**

## 使用

```bash
# 安装依赖（无，纯标准库）

python get\_super\_password.py --mac 你的光猫MAC --password 光猫背面密码

# 指定光猫地址
python get\_super\_password.py -i 192.168.1.1 -m 你的光猫MAC -p 光猫背面密码
```

## 参数

|参数|说明|
|-|-|
|`-i, --ip`|光猫地址，默认 `192.168.1.1`|
|`-m, --mac`|光猫 MAC（任意格式，必需）|
|`-u, --user`|普通用户名，默认 `useradmin`|
|`-p, --password`|光猫背面普通密码（必需）|
|`--port`|维护后台端口，默认 `8080`|

## 常见问题

|问题|原因|解决|
|-|-|-|
|su 密码 3 个全错|海思版，不是博通版|先确认 `BoardId` 是不是 `TY968`|
|set3\_sessionKey 抓不到|固件差异|认准 `set3\_sessionKey` 后面引号里的纯数字|
|开完 Telnet 连不上|端口没起来|等 2\~3 秒，或重复调一次接口|
